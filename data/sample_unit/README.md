# Sample unit outline

Grade 6, Unit 4 ELA: *The Lightning Thief* by Rick Riordan (ISBN 9780786838653). Scope and sequence provided with the brief as the input for generation.

- `lesson_outline.csv`: the "Lesson Outline" tab. Row 1 is a banner, row 2 the header (Filename, Lesson, Lesson #, Type of Lesson, Days, Text Dependent Question, Lesson Description, Text Set Choice, Homework, Focus Standards, Additional CA ELA Standards, CA Media Literacy Standards, Performance Task skills, Foundational Skills, Vocabulary, ...).
- `eld_scope_and_sequence.csv`: a hidden working tab with ELD standards, language/content objectives and ideas for Launch, Literacy Lab, Learning in Action and Look Back.

Vendor names in text-set references were replaced with "client library".
